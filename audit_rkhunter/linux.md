# **1\. Аутентификация и управление доступом**

## **1.1 Запрет пустых паролей**

**Команда проверки:**

```
awk -F: '($2=="") {print "Пустой пароль:"$1}' /etc/shadow
```

**Ожидаемый результат:** пустой вывод.

**Риски при активации:** отсутствуют.

* * *

## **1.2 Запрет входа root по SSH**

Добавить в `/etc/ssh/sshd_config`:

```
PermitRootLogin no

```

**Проверка:**

```
grep '^PermitRootLogin' /etc/ssh/sshd_config
```

**Риски:**

*   Неправильная настройка может заблокировать аварийный доступ (использовать sudo‑пользователей как резерв).
*   Требует наличия минимум 1 пользователя с правами sudo.

* * *

## **1.3 Ограничение su через pam\_wheel**

Добавить в `/etc/pam.d/su`:

```
auth required pam_wheel.so use_uid

```

**Риски:**

*   Пользователи вне группы wheel потеряют доступ к su.

* * *

## **1.4 Ограничение sudo**

**Проверка:**

```
visudo -c
```

**Риски:**

*   Ошибка в sudoers может полностью заблокировать управление сервером (рекомендуется проверять через `visudo`).

# **2\. Права доступа к системным файлам**

## **2.1 Права на passwd, shadow, group**

```
chmod 644 /etc/passwd /etc/group
chmod 600 /etc/shadow
```

**Риски:** отсутствуют.

* * *

## **2.2 Права на cron**

```
chmod go-w /etc/crontab
chmod go-w /etc/cron.d/*
```

**Риски:** отсутствуют.

* * *

## **2.3 Аудит SUID/SGID**

```
find / -perm /6000 -type f 2>/dev/null
```

**Риски:**

*   удаление SUID у системных программ может нарушить их работу.
*   требуется проверка каждой программы.

* * *

## **2.4 Закрытие домашнего каталога пользователя**

```
chmod 700 /home/<user>
```

**Риски:** отсутствуют.

# **3\. Настройки ядра Linux (sysctl)**

## **3.1 Защита журнала ядра**

```
kernel.dmesg_restrict=1
```

**Риски:** отсутствуют.

* * *

## **3.2 Ограничение утечек через kallsyms**

```
kernel.kptr_restrict=2
```

**Риски:** отсутствуют.

* * *

## **3.3 Защита mmap / ASLR**

```
vm.mmap_min_addr=4096
kernel.randomize_va_space=2
```

**Риски:** отсутствуют.

* * *

## **3.4 ptrace защита**

```
kernel.yama.ptrace_scope=3
```

**Риски:**

*   могут не работать инструменты мониторинга, профилирования.
*   затрагивает агенты MaxPatrol, syslog (SIEM KUMA).

* * *

## **3.5 Защита symlink/hardlink**

```
fs.protected_symlinks=1
fs.protected_hardlinks=1
```

**Риски:** отсутствуют.

* * *

## **3.6 FIFO и регулярные файлы**

```
fs.protected_fifos=2
fs.protected_regular=2
```

**Риски:** отсутствуют.

* * *

## **3.7 Запрет core dump**

```
fs.suid_dumpable=0
```

**Риски:** отсутствуют.

* * *

## **3.8 Запрет user namespaces**

```
user.max_user_namespaces=0
```

**Риски:**

*   ломает Docker / containerd / Podman;
*   ломает sandbox браузеров.

* * *

## **3.9 Ограничение eBPF**

```
kernel.unprivileged_bpf_disabled=1
net.core.bpf_jit_harden=2
```

**Риски:**

*   может нарушить работу сетевых агентов;
*   риск с MaxPatrol VM, SIEM KUMA.

* * *

## **3.10 perf события**

```
kernel.perf_event_paranoid=3
```

**Риски:**

*   инструменты мониторинга CPU могут перестать работать;
*   MaxPatrol VM не поддерживает этот параметр.

# **4\. Параметры загрузчика (GRUB)**

  

Добавить в `/etc/default/grub` → `GRUB_CMDLINE_LINUX_DEFAULT`.

* * *

## **4.1 Инициализация памяти нулями**

```
init_on_alloc=1

```

**Риски:**

*   снижение производительности (1–7%);
*   влияет на SIEM KUMA, MaxPatrol.

* * *

## **4.2 Запрет slab слияния**

```
slab_nomerge

```

**Риски:** небольшое падение производительности.

* * *

## **4.3 TSX выключение**

```
tsx=off

```

**Риски:** падение производительности на старых CPUs.

* * *

## **4.4 Включение IOMMU**

```
iommu=force iommu.strict=1 iommu.passthrough=0

```

**Риски:**

*   возможны проблемы с виртуализацией;
*   возможна деградация сетевой производительности;
*   риски на MaxPatrol VM.

* * *

## **4.5 Запрет vsyscall**

```
vsyscall=none

```

**Риски:** старые бинарные программы могут перестать работать.

* * *

## **4.6 Отключение debugfs**

```
debugfs=no-mount

```

**Риски:** некоторые драйверы оборудования используют debugfs.

* * *
